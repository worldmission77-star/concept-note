# 개념노트

학생별 개념 정리 노트 앱 (Flask + SQLite), 휴대폰 접속 지원 (반응형)

## 로컬 실행 방법

```bash
pip install -r requirements.txt
python app.py
```

처음 실행 시 `concept_note.db`가 자동 생성됩니다.
브라우저에서 http://localhost:5000 접속 후 관리자 계정(`admin` / `admin1234`)으로 로그인 → 학생 관리에서 학생 계정을 만들어주세요.
같은 와이파이의 폰에서 접속하려면 `http://<컴퓨터의-내부IP>:5000` 으로 접속하세요.

## 기능

**학생**
- 자율 회원가입은 없습니다. 계정은 관리자(선생님)가 만들어 아이디/비밀번호를 알려줍니다.
- 로그인 / 로그아웃 (세션 기반, 본인 노트만 조회 가능)
- 노트 목록: 제목, 날짜, 내용 미리보기, 사진 썸네일, 선생님 확인 여부 표시
- 노트 작성 / 수정 / 삭제, 사진 1장 첨부
- 선생님이 남긴 코멘트를 노트 상세 화면에서 확인
- 모바일 반응형 (휴대폰 화면에서 1~2열 목록, 터치하기 편한 버튼 크기)

**관리자 (선생님)**
- 기본 관리자 계정: 아이디 `admin` / 비밀번호 `admin1234` (아래 "관리자 계정" 참고, 꼭 변경하세요)
- **학생 계정 생성**: 학생 관리 화면에서 "+ 학생 계정 추가"로 아이디/비밀번호/이름/학년/연락처를 입력해 계정을 만들고, 학생에게 아이디/비밀번호를 알려주면 됩니다
- 전체 학생의 노트를 한 화면에서 확인 (학생별, 날짜별 필터)
- 학생 목록 및 연락처(학생/부모님) 확인
- 노트에 확인 도장("참 잘했어요") 찍기 + 코멘트(피드백) 남기기 → 학생 화면에 바로 표시됨
- 노트 삭제, 학생 계정 삭제(해당 학생의 모든 노트도 함께 삭제)
- **학부모 확인 링크**: 노트 상세 화면에 로그인 없이 접속 가능한 전용 링크가 자동 생성됩니다. 문자/카카오톡으로 학부모님께 전달하면, 학부모님이 아이의 노트를 보고 "우리 아이가 잘 이해했어요" 버튼을 눌러 확인 도장을 남길 수 있습니다. 링크가 유출되면 "링크 재발급" 버튼으로 기존 링크를 무효화할 수 있습니다.
- 문자(SMS) 자동 전송 기능은 아직 포함되어 있지 않아 링크를 수동으로 복사해 보내야 합니다. 필요하시면 알리고(Aligo) 등 SMS API 연동을 별도로 추가해드릴 수 있어요.

### 관리자 계정 설정

기본값은 아이디 `admin`, 비밀번호 `admin1234` 입니다. 배포 전에 반드시 아래처럼 환경변수로 바꿔주세요 (로컬 실행 시에도 동일):

```bash
export ADMIN_USERNAME=원하는아이디
export ADMIN_PASSWORD=원하는비밀번호
```

**주의**: 이 값은 `concept_note.db` 파일이 처음 생성될 때만 적용됩니다. 이미 DB가 만들어진 뒤 바꾸려면 DB 파일을 지우고 다시 시작하거나, 관리자 계정 비밀번호를 직접 DB에서 변경해야 합니다.

## 인터넷 배포하기 (Render 기준, 무료 티어 가능)

아이들이 각자 폰으로 아무 데서나 접속하려면 서버를 인터넷에 올려야 합니다.

1. 이 프로젝트를 GitHub 저장소에 올립니다.
2. [render.com](https://render.com) 가입 후 **New + → Web Service** 선택, 방금 올린 저장소를 연결합니다.
3. 설정값:
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `gunicorn app:app --bind 0.0.0.0:$PORT` (Procfile이 있으면 자동 인식됨)
4. **Environment** 탭에서 환경변수 추가:
   - `SECRET_KEY`: 임의의 긴 랜덤 문자열 (예: `python -c "import secrets; print(secrets.token_hex(32))"` 로 생성)
   - `DATA_DIR`: `/var/data` (아래 5번의 디스크 마운트 경로와 동일하게)
   - `FLASK_DEBUG`: `0`
5. **Disks** 탭에서 Persistent Disk를 추가하고 **Mount Path**를 `/var/data`로 설정합니다.
   - SQLite 파일과 업로드된 사진은 여기에 저장됩니다.
   - 이 디스크가 없으면 재배포할 때마다 회원 정보와 노트가 모두 사라집니다. **꼭 설정하세요.**
6. 배포가 끝나면 `https://your-app.onrender.com` 같은 주소가 생기고, 아이들은 폰 브라우저에서 이 주소로 접속하면 됩니다.

### 참고
- 무료 티어는 일정 시간 요청이 없으면 서버가 슬립 상태가 되어, 다시 접속할 때 첫 로딩이 몇 초 느릴 수 있습니다.
- 업로드 용량 제한은 8MB로 설정되어 있습니다 (`app.py`의 `MAX_CONTENT_LENGTH`).
- Railway, Fly.io 등 다른 플랫폼도 비슷한 방식(빌드 명령 + 시작 명령 + 영구 디스크)으로 배포할 수 있습니다.
